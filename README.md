# Atividade01 — TypeScript

Essa é uma atividade que fiz pra praticar os conceitos básicos de TypeScript.

## O que eu fiz

- Criei uma variável para cada tipo primitivo: string, number e boolean.
- Fiz uma função que recebe nome, idade (opcional) e ativo (com valor padrão).
- Usei type alias pra criar um "molde" de objeto (Usuario) e uma função que devolve um objeto nesse formato.
- Fiz uma condição com if/else pra classificar a idade.
- Fiz um for que repete várias vezes usando a variável idade como limite.
- Fiz um switch pra comparar a idade com alguns valores fixos.

## Como rodar

npm install
npx tsc
node dist/atividade01.js
